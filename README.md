# 字幕自动截屏工具 🎬

看剧看电影时，**对白每变化一次就自动截一张全屏图**，从此不用为了截图反反复复按快捷键、暂停播放，专注观影不打断。

## ✨ 功能特性

- 🎯 **智能字幕检测**：框选屏幕字幕所在区域，程序自动监测画面变化
- ⚡ **毫秒级响应**：每 0.25 秒采样一次，对白切换立即截图
- 🛡️ **防抖机制**：内置冷却时间，同一句对白不会被连拍多张
- 🖼️ **实时预览**：右侧面板实时显示字幕区域画面，所见即所得
- 🎛️ **参数可调**：检测灵敏度、防抖时长随时拖动调整
- 🌈 **温和界面**：奶油米白配色 + 圆角卡片，看剧时也不刺眼
- 📦 **单文件 exe**：打包后无需 Python 环境即可运行

## 📸 工作原理

```
┌─────────────────────────────────────────────┐
│  播放器画面（含字幕）                          │
│                                              │
│                                              │
│         ┌──────────────────────┐            │
│         │ 框选的字幕检测区域    │ ◀── 每0.25秒采样
│         └──────────────────────┘            │
└─────────────────────────────────────────────┘
                    │
                    ▼
        ┌───────────────────────────┐
        │ 与上一帧做像素差异比较      │
        │ 差异 ≥ 阈值 → 字幕变了     │
        └───────────────────────────┘
                    │ 变化
                    ▼
        ┌───────────────────────────┐
        │ 保存全屏截图到指定目录      │
        │ 进入防抖冷却期（默认1.5s） │
        └───────────────────────────┘
```

## 🚀 快速开始

### 方式一：直接运行 exe（推荐普通用户）

1. 前往 [Releases](../../releases) 下载 `字幕自动截屏工具.exe`
2. 双击运行
3. 无需安装任何依赖

### 方式二：从源码运行

```bash

# 2. 启动程序

```

> 需要 Python 3.9+ 和 Pillow 库。

## 📖 使用说明

### 三步上手

1. **选保存目录**：点击「选择…」挑一个截图存放位置
2. **框选字幕区域**：点击「框选区域」→ 主窗口自动最小化 → 按住鼠标左键在屏幕底部拖一条字幕区域（把字幕条完整框进去）
3. **开始检测**：回到主界面，右侧会实时显示你框选到的字幕预览，确认无误后点「▶ 开始检测」

接下来就可以躺平看剧啦！每次对白切换都会自动保存一张全屏截图。

### 参数调节

| 参数 | 默认值 | 调节建议 |
|------|--------|----------|
| **差异阈值** | 4.0 | 误触发多 → 调高到 6~10；漏拍 → 调低到 2~3 |
| **防抖时长** | 1.5s | 对白密集 → 调到 0.5~1s；正常节奏 → 保持 1.5s |

左侧「当前差异」数值可以帮你观察字幕变化强度，方便微调阈值。

## ⚙️ 技术细节

- **GUI 框架**：tkinter（Python 标准库，无需额外安装）
- **图像处理**：Pillow（PIL.ImageGrab 截屏 + ImageChops 差异比较）
- **比较算法**：字幕区域缩放到 480×80 灰度图，用 histogram 统计平均像素差异，O(1) 复杂度
- **多线程**：检测循环跑在后台守护线程，GUI 主线程不阻塞
- **多显示器**：支持 `all_screens=True`，跨屏截屏也能正常工作
